# PhD Studio 设计文档（v2）

> 本地运行的 PhD 科研工作台。v1 是"开源缝合调研 + PRD"，v2 把 v1 的需求和后来对话里新增的需求合在一起，标出现状，并给出待建模块的设计。
> 状态：✅ 已实现并实测 · 🟡 部分实现 · ⬜ 未实现 · 🆕 v1 里没有、新增的需求

## 1. 定位与原则

- **数据只在本地。** Obsidian vault 和 Zotero 是唯一真相源。工作台主要做"读"，以及"一个顺手的 Claude 窗口"。
- **改 vault 要确认，例外很少。**
  - Claude 改任何笔记，都先给你看差异，你点"允许"才写入。
  - 例外只有阅读清单、规划、想法这类结构化数据：工作台直接写，但只写各自那一个 YAML 文件。
- **界面极简。** 苹果/谷歌式风格，左侧导航，少文字、多数字和图，细节点开再看。
- **不悄悄换模型。** Claude 不可用就直接报错，不会偷偷改用别的模型。
- **两台 Mac 同步安全。** 状态按设备分开存。两边同时改的结构化数据会自动合并冲突。大文件不进同步。
- **开源但匿名。** 代码在公开仓库，所有个人信息只放在不进仓库的 `studio.toml`。

## 3. 已实现的模块

| 模块 | 功能 |

## 4. 待建模块设计

左侧导航扩展为：**总览 · 清单 · 时间线 · 想法 · 方向 · 追踪**，下面放设置和关闭。

### 4.1 总览（新的首页）
- **一排数字：**
  - 下一个截稿还剩几天，同时标出是哪个会、绑定了哪篇论文；
  - 本周 T1 数量；
  - 收件箱数量；
  - 未整理的 idea 数量；
  - 本周追踪到的新论文数量。
- **未来 90 天时间轴：**
  - 在一条横轴上标出三类点：顶会截稿、目标截稿、个人里程碑；
  - 今天是一条竖线；
  - 鼠标悬停看详情。
- **研究线状态卡：** 每条研究线一张卡，写着当前阶段、最近一个 Gate、Kill criteria 灯。

### 4.2 时间线：三类 deadline
- **顶会截稿：**
  - 数据来自 ccfddl/ccf-deadlines 开源数据，每天刷新一次，界面上标明来源；
  - 摘要和全文截止时间都从 AoE 换算成本地时区；
  - 显示 CCF / CORE 等级；
  - 只显示关注的会议，关注列表放在 `studio.toml`。
- **目标截稿：** 研究线 → 目标会议（含备选）；截稿日期自动取自顶会数据。
- **个人规划：**
  - 里程碑字段：日期、研究线、状态（待开始/进行中/完成/预警）、备注；
  - Gate 和 Kill criteria 也作为里程碑存。
- **存储：** 全部存在 vault 里的一个 YAML 文件（例如 `00 Atlas/plan.yaml`），沿用阅读清单的同步安全写法。
- **命令行：** `studio milestone add/done`，其他会话也能更新进度。

### 4.3 想法：idea 捕捉
- **随手记：**
  - 任何页面按 ⌘I 弹出一个输入框，一句话就能存；
  - 自动附上当时正在读的论文和页码；
  - 可选研究线标签。
- **收件箱：**
  - 想法按时间排列；
  - 可打标签、合并、丢弃，丢弃的保留记录。
- **整理成正式笔记：**
  - 点"整理成 idea 笔记"，Claude 按 AGENTS.md 的 Idea 结构起草：问题、为什么是现在、技术核心、第一个实验、Kill criteria、下一步证据；
  - 经你确认后写入 `02 Ideas/`，并链接到相关论文。
- **存储：** `02 Ideas/ideas.yaml`（同步安全）。
- **命令行：** `studio idea "…"`，其他会话也能记想法。

### 4.4 方向：roadmap 与研究线
- **研究线卡片：**
  - 数据从 vault 读取：Research Line 笔记、PhD Roadmap、Idea Radar；
  - 每张卡显示：阶段、目标会议与倒计时、Gate 列表（日期 + 状态灯）、Kill criteria（未触发/部分触发/触发）、关联论文数（来自阅读清单分组）、关联 idea 数。
- **路线图：** 3 年阶段图，标出当前位置。
- **点开一条研究线：**
  - 看笔记全文；
  - "和 Claude 讨论这条线"：每条线一个持续会话，挂载路线图、Evidence 和 Review Packets；
  - 可让 Claude 起草导师汇报包或更新 Idea Radar，写入前要你确认。
- **Reading Course：** 课程里的每一课显示为闯关进度。

### 4.5 追踪：同行动态 + 捕捉面板
- **本周雷达：**
  - 展示 research_tracker 最新一次运行：Tier A/B/C 数量、周报摘要；
  - 论文列表每条可"加入清单"或"忽略"。
- **实验室 / 学者：**
  - 列出关注的约 48 个实验室和学者；
  - 显示每个的近期论文数和最近一篇；
  - 点开看该实验室的笔记。
- **捕捉面板：**
  - 粘贴 arXiv / OpenReview / DOI 链接或论文标题，进收件箱，附一句理由；
  - "关注这个人/实验室"或"关注这个关键词"，追加到 tracker 的关注列表，下次巡检生效。
- **立即巡检（后做）：** 在工作台里手动触发一次 tracker。

### 4.6 其他待补
- 划词"摘录到笔记"：一步追加到笔记的指定小节，带页码。
- 笔记里的 [p.5] 点击跳页。
- "Claim Gate 审计"快捷指令。
- 多模型接入：Codex、Gemini、智谱。

## 5. 数据与同步约定

| 数据 | 位置 | 谁写 | 同步 |
|---|---|---|---|
| 论文笔记、路线图、idea 笔记 | vault | 你（Obsidian）；Claude 经你确认后写 | Syncthing |
| 阅读清单、规划、想法 | vault 内各一个 YAML | 工作台、`studio` 命令 | Syncthing；冲突自动合并 |
| 生成的摘要笔记（如 Reading List.md） | vault | 工作台 | Syncthing；冲突时重新生成 |
| 对话记录、会话 id、设置 | `phd_studio/state/<设备名>/` | 该设备 | 同步，但每台只写自己的子文件夹 |
| PDF 缓存、双语 PDF、截图 | `~/Library/Application Support/PhD Studio/` | 工作台 | 不同步 |
| 密钥（Claude 令牌、DeepSeek） | `~/.config/secrets/` | 你 | 按你原有设置同步 |

## 6. 建议的开发顺序

1. 时间线（三类 deadline）+ 总览。截稿最紧，最先用得上。
2. 想法捕捉（⌘I 和 `studio idea`）。
3. 追踪页 + 捕捉面板。
4. 方向页（研究线卡片 + 和 Claude 讨论）。
5. 4.6 里的小项和多模型接入，按需要再做。

每个模块做完都在浏览器里实测，再交给你用。
